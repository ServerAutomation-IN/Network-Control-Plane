# Product Roadmap

```text
MVP-0 (Foundation) ──> MVP-1 (Discovery) ──> MVP-2 (Management) ──> MVP-3 (Topology)
         │
         └──> MVP-4 (IPAM) ──> MVP-5 (Multi-Host) ──> MVP-6 (Governance)
                    │
                    └──> MVP-7 (Drift/GitOps) ──> MVP-8 (Agentic AI) ──> MVP-9 (Enterprise Secrets)
```

- **Phase 1 (MVP-0 to MVP-2):** Single Docker Host Foundation, Network Discovery, Safe Management & Audit.
- **Phase 2 (MVP-3 to MVP-4):** Interactive React Flow Graph Topology & IPAM Conflict Engine.
- **Phase 3 (MVP-5 to MVP-6):** Multi-Host Fleet Management, Agent Protocol, Policy Compliance, RBAC.
- **Phase 4 (MVP-7 to MVP-8):** Desired-State Drift Reconciliation & Human-in-the-Loop Agentic AI Diagnostics.
- **Phase 5 (MVP-9 / Phase H):** Enterprise Secrets & Key Vault Integration (HashiCorp Vault, AWS Secrets Manager, Azure Key Vault).
