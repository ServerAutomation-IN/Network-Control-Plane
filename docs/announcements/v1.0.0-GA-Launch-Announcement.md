## 🚀 The Missing Layer in Modern Infrastructure

Over the last decade, compute orchestration evolved from static virtual machines to dynamic container clusters, serverless workloads, and distributed edge nodes. Yet, the foundational layer binding these workloads together—**workload networking**—remains trapped in the past.

Platform engineers and DevOps teams are forced to wrestle with:
1. **Network Blindness:** Inability to visualize live container-to-network topologies across multiple hosts, Docker daemons, Swarm overlays, and cloud VPCs in real-time.
2. **Silent IPAM & Subnet Collisions:** Overlapping CIDR allocations between bridge networks, VPN gateways, and cloud subnets that cause intermittent, silent connection drops and routing loops.
3. **Configuration Drift & Operational Fragility:** Manual `docker network create` commands or ad-hoc shell scripts diverging unpredictably from infrastructure-as-code repositories.
4. **Dangerous Network Mutations:** Detaching a container or tearing down an overlay network without knowing its blast radius or impact on downstream microservices.
5. **Credential & Secret Sprawl:** Hardcoded daemon certificates and plaintext tokens scattered across deployment files.

Today, we are thrilled to announce the General Availability of **Network Control Plane v1.0.0-GA**—an open-source, enterprise-grade, and provider-neutral control plane that unifies discovery, visualization, IP address management (IPAM), policy governance, GitOps reconciliation, and governed AI diagnosis into a single pane of glass.

- **Invariant A1 — Provider Neutrality:** Core domain models (`backend/app/models/`, `schemas/`, `services/`, `ipam/`, `policy/`) never import provider-specific SDKs. Docker, Podman, Cilium, and Cloud VPC code resides strictly inside isolated provider adapters.
- **Invariant A2 — Adapter Isolation:** Adapters communicate through standardized capability contracts (`discover`, `inspect`, `create_network`, `delete_network`, `attach_endpoint`, `detach_endpoint`).
- **Invariant A3 — Read Before Write & Safety Verification:** Every mutating action undergoes pre-flight validation, automated blast-radius risk evaluation (`LOW`, `MEDIUM`, `HIGH`, `CRITICAL`), user confirmation, and immutable audit event logging.
- **Invariant A4 — API Socket Isolation:** Frontend dashboards never touch Docker sockets or cloud APIs directly; every request is authenticated, RBAC-checked, and validated through the FastAPI API gateway.

## 🌟 What's Inside v1.0.0-GA

### 1. Interactive Real-Time Topology Canvas
Powered by **React Flow** and the **ELK.js layout engine**, Network Control Plane generates interactive, hierarchically organized topology graphs of your infrastructure.
- **Live State Updates:** Subscribes to real-time Server-Sent Events (SSE) and WebSockets to instantly update node and link statuses when containers spin up or disconnect.
- **Side Panel Deep Inspection:** Click any network node, subnet boundary, or container endpoint to view IP allocations, gateway addresses, driver flags, and custom labels.
- **Dynamic Search & Filtering:** Filter multi-host clusters by driver type (`bridge`, `overlay`, `macvlan`), environment tag, or host ID.

### 2. Intelligent IP Address Management (IPAM)
Network Control Plane treats IP space as a critical production resource:
- **Capacity & Density Tracking:** Computes subnet utilization percentage, total assignable slots, allocated IP counts, and unallocated address pools in real time.
- **Cross-Network CIDR Conflict Engine:** Automatically evaluates proposed and existing subnets across all hosts and cloud regions to prevent overlapping CIDR blocks and conflicting gateway assignments.
- **Static IP Verification:** Prevents duplicate IP assignments with deterministic validation before workloads are scheduled.

### 3. Pre-Flight Safety Risk Engine & Governance
Say goodbye to accidental outages caused by rogue network deletes:
- **Blast-Radius Scoring:** Evaluates active container connections, dependent gateways, and connected services to classify mutations into `LOW`, `MEDIUM`, `HIGH`, or `CRITICAL` risk tiers.
- **Declarative Governance Policies:** Enforce enterprise standards with customizable rules (e.g., mandate internal-only isolation, disallow legacy drivers, require mandatory security labels, enforce approved CIDR allocations).
- **Role-Based Access Control (RBAC):** Built-in support for `Administrator`, `Operator`, and `Viewer` personas.

### 4. Continuous GitOps & Drift Reconciliation
Declare your desired networking state in version control and let Network Control Plane maintain parity:
- **Declarative YAML Schema (`network-control-plane/v1`):** Define desired networks, subnets, gateways, and container attachments in simple YAML manifests.
- **Continuous Drift Detection:** Periodically pulls from GitHub, GitLab, or Bitbucket to detect divergence between active runtime state and Git manifests.
- **Human-Approved Reconciliation:** View unified visual diffs and approve automated reconciliation jobs executed asynchronously via Redis and ARQ.

### 5. Enterprise Zero-Trust Secrets & SSO
- **Dynamic URI Secrets Resolution:** Configure connection credentials using dynamic URI references (`vault://`, `aws-secret://`, `azure-vault://`, `fernet://`).
- **Enterprise Key Vault Support:** First-class integrations with HashiCorp Vault (KV v1/v2), AWS Secrets Manager, and Azure Key Vault.
- **Single Sign-On (SSO):** OIDC and SAML 2.0 integration with Okta, Microsoft Entra ID, and Keycloak.
- **Outbound Webhooks:** HMAC SHA-256 signed webhooks notifying external systems of network mutations.

### 6. Governed Human-in-the-Loop AI Diagnostics
- **Automated Reachability Diagnostic Engine:** Topology graph traversal diagnosing container reachability problems, network isolation, and route path mismatches.
- **Natural Language Inventory Queries:** Query complex infrastructure state in plain English (e.g. *"Find all isolated bridge networks in staging with more than 50% IP capacity used"*).
- **Mandatory Human-in-the-Loop Approval:** The AI assistant can formulate remediation proposals, but **CANNOT** mutate infrastructure without explicit user sign-off in the UI.

## ⚡ 60-Second Quickstart

Get started locally in under a minute with Docker Compose:

```bash
# 1. Clone the repository
git clone https://github.com/ServerAutomation-IN/Network-Control-Plane.git
cd Network-Control-Plane

# 2. Launch multi-tier production stack
docker compose -f deployment/docker-compose.yml up -d

# 3. Access the services
# - Web Dashboard:          http://localhost:3001
# - Interactive API Docs:   http://localhost:8000/docs
# - Prometheus Metrics:     http://localhost:8000/metrics
```
